Análisis bioinformático de variantes del gen CFTR asociadas a fibrosis quística

Descripción del proyecto

La fibrosis quística es una enfermedad genética autosómica recesiva causada por variantes patogénicas en el gen CFTR (Cystic Fibrosis Transmembrane Conductance Regulator). Este gen codifica una proteína de membrana que interviene principalmente en el transporte de iones cloruro y bicarbonato a través de las células epiteliales. Las alteraciones en su funcionamiento pueden afectar a distintos órganos, especialmente a los sistemas respiratorio y digestivo.

Este proyecto tiene como finalidad desarrollar un análisis bioinformático básico de variantes del gen CFTR relacionadas con la fibrosis quística, utilizando información procedente de bases de datos públicas y herramientas de programación científica.

Objetivos

Objetivo general:

Analizar y comparar variantes genéticas del gen CFTR asociadas a fibrosis quística mediante un procedimiento bioinformático reproducible.

Objetivos específicos:

1. Consultar información genética y clínica del gen CFTR en bases de datos públicas.
2. Seleccionar un conjunto de variantes relevantes, incluyendo F508del.
3. Organizar la información obtenida en archivos CSV.
4. Desarrollar un script en Python para procesar y resumir los datos.
5. Documentar la metodología y los resultados del análisis.

Metodología

El proyecto se desarrollará en las siguientes fases:

1. Recopilación de información: consulta de bases de datos como NCBI, ClinVar y UniProt para obtener información del gen CFTR y sus variantes.
2. Preparación de los datos: selección y organización de las variantes en un archivo CSV con campos identificativos y anotaciones clínicas.
3. Procesamiento mediante Python: desarrollo de un script para leer los datos, comprobar su estructura y generar un resumen de las variantes estudiadas.
4. Interpretación de resultados: descripción de las variantes seleccionadas y de su posible relevancia clínica a partir de las anotaciones disponibles.

Las clasificaciones clínicas se recogerán de las fuentes consultadas y no se considerarán resultados de una validación experimental propia.

- LICENSE: licencia del repositorio.

Herramientas y recursos

- Python: procesamiento y análisis básico de los datos.
- Git y GitHub: control de versiones y organización del proyecto.
- NCBI: información de referencia sobre el gen CFTR.
- ClinVar: consulta de variantes y sus interpretaciones clínicas.
- UniProt: información funcional de la proteína CFTR.
